# Hey, I'm Aditya

I build things because I want to understand how they work.

That curiosity has taken me from real-time collaborative systems, where multiple people can shape the same data, to AI applications that search documents for answers grounded in their contents.

I enjoy going beyond making something work understanding the decisions behind it, the problems they create, and how to make things better.

->exploring real-time collaboration, CRDTs, and the challenge of keeping shared state in sync.

- **[Marvealle E-commerce Website](https://github.com/MaybeAditya/Marvealle_Fashion_Atlier)** —> building an e-commerce experience and exploring how to turn an idea into a functional product.

I'm drawn to problems at the intersection of systems, software, and applied AI. Most of all, I like learning by building — turning questions into working software, then figuring out what could be better.
