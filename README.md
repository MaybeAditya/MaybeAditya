# Hey, I'm Aditya 👋

I build things because I want to understand how they work.

That curiosity has taken me from real-time collaborative systems, where multiple people can shape the same data, to AI applications that search documents for answers grounded in their contents.

I enjoy going beyond making something work — understanding the decisions behind it, the problems it creates, and how to make it better.

- **[Document Analyst](https://github.com/MaybeAditya/Document-Analyser)** — exploring how retrieval, embeddings, and language models work together to make documents searchable.
- **[Crop Disease Detection](https://github.com/MaybeAditya/Explainable-AI-based-Crop-Disease-Detection-System-using-Leaf-Image-Analysis)** — exploring computer vision and how AI predictions can become more interpretable.

I'm drawn to problems that sit at the intersection of systems, software, and applied AI. Most of all, I like learning by building — turning questions into working software, then figuring out what could be better.
